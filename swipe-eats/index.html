Online mód beállítása

🔥 Firebase beállítása

Az online mód egyszer igényel ~5 perces beállítást. Utána mindörökre ingyen működik.

  1. Nyisd meg: console.firebase.google.com
  2. "Add project" → adj nevet → Continue × 2
  3. Bal menü: Build → Realtime Database → Create database → "Start in test mode" → Enable
  4. Bal menü: Project Overview ⚙️ → Project settings → Your apps → kattints a </> ikonra → adj nevet → Register app
  5. Másold ki a firebaseConfig objektumot
  6. A repóban nyisd meg: swipe-eats/firebase-config.js és illeszd be a konfigot

Az ingyenes Spark csomag elegendő (1 GB tárhely, 100 egyidejű kapcsolat)
